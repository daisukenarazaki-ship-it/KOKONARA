## 受注ポリシー（Skill①が参照する判断基準）

- 記事の最低受注単価: 3,000円/記事（文字単価0.6円を下回る案件は提案しない）
- LP/HPの最低受注単価: 30,000円
- 受けない案件: 医療・法律・金融の専門記事（YMYL） / アダルト / 情報商材の宣伝記事 / 納期3日以内の大型案件 / 「テストライティング無料」要求
- 納期の目安: 記事1本=受注確定から2〜4日 / LP=受注から14日（平日1〜2時間稼働で守れる値だけ約束する）
- 提案で優先するジャンル: 転職・キャリア / 飲食 / IT・広告（得意分野は単価交渉でも強気でよい）

## 定型文パーツ

- AI活用の開示方針: 「リサーチ・構成・下書きにAIを活用し、短納期・低価格を実現しています。事実確認と最終仕上げは必ず人間が行い、AIの文章をそのまま納品することはありません」
