## 呼び出し方

**Claude Code（Opus 4.8等・このリポジトリで起動）:**
リポジトリを開けばSkillは自動認識される。
- `今日のタスクを教えて` → daily-ops
- `この依頼に提案文を書いて: （依頼文コピペ）` → proposal-writer
- `今週の台本5本作って` → video-script
- `先週の数字: #1が2400再生…` → video-script モードB
- `noteの有料記事を作りたい` → note-writer
- 明示的に呼ぶなら `/video-script` のようにスラッシュ指定

**claude.ai / デスクトップアプリ（チャット）で使う場合:**
該当する `SKILL.md` の本文（---の下から）を会話の最初に貼り付けて「このSkillに従って」と依頼する。プロジェクト機能があるなら、7つのSKILL.md＋profile.md＋dashboard.mdをプロジェクトナレッジに登録しておくと毎回貼らずに済む。
※ genre-research はWeb検索が使えるモデル/プランで実行すること。

## 安全原則（全Skill共通）

1. **送信・投稿・公開・課金・ASP登録は必ず人間が行う。** AIの出力は常に下書き。
2. **アフィリエイト投稿には #PR 表記必須**（ステマ規制）。台本の【PR表記済み】印を投稿前に確認。
3. **実績数字は log.md / dashboard.md の実数のみ。** 動画・noteでの収益の捏造は絶対禁止。
4. `【要確認】` `【要記入】` は創作防止の正常動作。埋めるのは人間。
5. 案件ファイルは `projects/` 配下。雛形（リポジトリ直下）は編集しない。
6. クライアント情報をSNS・note・他案件に転用しない（動画に案件画面を映さない）。
