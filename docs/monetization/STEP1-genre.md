# STEP1: ジャンル選定

作成日: 2026-07-05
前提: 実務経験ほぼゼロ / AI(Claude Code等)フル活用 / 平日1〜2時間 / 営業チャネルは全部使える

## 結論

**「AIコンテンツ制作の受注販売」＋「SNSアフィリエイト×note」の3本柱でやる。**（柱Cは2026-07-05追加）

| 柱 | 内容 | 役割 | 想定単価/収益 |
|---|---|---|---|
| 柱A | SEO記事・ブログ記事の作成代行 | 回転率担当。案件数が多く初受注を取りやすい。評価(レビュー)を貯める | 1記事 3,000〜10,000円 |
| 柱B | 店舗向けLP・ホームページ制作 | 単価担当。RE:BIRTHサンプルが既にあり、即ポートフォリオにできる | 1件 30,000〜100,000円 |
| 柱C | SNSショート動画アフィリエイト＋note販売（ジャンル: AI×副業。切り口は金銭欲求直結の「実績ゼロからの実録」。research/2026-07レポート＋追補参照） | 資産担当。フォロワーとnote記事は積み上がる。収益は遅行（9月〜） | アフィ月0〜1万＋note月0〜1.5万(3ヶ月目) |

販売チャネル: ココナラ(出品+公開依頼への提案) / クラウドワークス・ランサーズ(提案営業) / TikTok+Instagramリール+YouTubeショート(同一動画を3面投稿) / note / X(実績発信)

柱の連動: 受注活動の実録がSNSと noteのネタになり、SNSフォロワーが受注とnote販売の集客になる。1つの作業が3方向に効く設計。

### 選定理由

1. **初受注までの距離が最短**: 記事作成代行は常時大量の公開依頼があり、実績ゼロでも低価格スタートで受注可能。
2. **AIとの相性が最良**: 執筆・構成・コーディングは工程の8割をAIに任せられる。人間は判断と品質確認に集中できる。
3. **既存資産が使える**: このリポジトリのRE:BIRTHサイトがそのまま柱Bのポートフォリオになる。
4. **月5万の算数が現実的**: 例) 記事5,000円×6本 + LP 30,000円×1件 = 60,000円/月。平日1〜2時間で到達可能な作業量。
