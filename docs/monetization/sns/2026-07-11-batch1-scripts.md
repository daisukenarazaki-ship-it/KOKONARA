フェーズ: T1（フォロワー1,000未満・フォロワー獲得全振り）
ジャンル: AI×副業の実録（金銭欲求直結）
配分: お役立ち4本＋実録2本。アフィ誘導なし。
撮影の絶対ルール: クライアントの依頼文・店名・金額が映る画面は録画しない（守秘）。映してよいのは自分のClaude Code画面・自分の出品ページ・テロップのみ。

3媒体（TikTok / Instagram / YouTube）を同一名義「だいすけ」で作成。プロフィール文:

```

実績ゼロ・レビューゼロからAI副業をスタート／出品・提案・受注までの過程を毎日記録
AI×副業の効率化テクも発信
```

要点: 3媒体に同じ動画を投稿（1本で3面展開）/ ジャンルを絶対ブラさない / フォロワー購入・相互フォローはしない。
