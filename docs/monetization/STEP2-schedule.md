毎日の流れは「Skill④ daily-ops」に状況を伝えるだけで、その日のTODOが出てくる設計。

## Phase 1以降: 毎日のルーティン（平日）

```
1. [10分] 提案タイム
   ココナラ公開依頼・クラウドワークスの新着から候補を2〜3件コピペ
   → Skill①(proposal-writer) で提案文生成 → 自分で確認して送信

2. [40〜70分] 制作タイム（上から優先）
   a. 納期が近い受注案件がある → その納品作業（Skill②/③）
   b. 受注ゼロ → ポートフォリオ追加 or 出品ページ改善 or X投稿ネタ作成

3. [5〜10分] 記録タイム
   docs/monetization/log.md に今日の結果を1行追記
   （提案数 / 返信数 / 受注数 / 売上 / メモ）
```

**毎日やるのは「Skill④ daily-ops を呼んで、出てきたTODOをこなす」だけ。**
迷ったら daily-ops に「今日は◯分ある、受注は◯件」と伝えれば上のルールで采配される。

## 週次レビュー（金曜 or 日曜、15分）

- log.md の1週間分を見て: 提案◯件→返信◯件→受注◯件 の歩留まりを確認
- 提案10件で返信0なら: 提案文か出品価格を見直す（Skill①のNG例に照らす）
- 受注が回り始めたら: 提案数を減らして制作時間を増やす
