## 週間ルーティン（Phase 1以降）

### 平日（60〜90分）

```
1. [10分] 提案タイム: 公開依頼2〜3件 → Skill① → 確認して送信
2. [15分] SNSタイム: ストックから1本投稿（キャプションは台本のコピペ）＋コメント返信
3. [残り時間] 制作タイム（優先順）:
   a. 納期が近い受注案件（Skill②/③）
   b. note記事の下書き（Skill⑦、週1本）
   c. ポートフォリオ追加 or 出品ページ改善
4. [5分] 記録: log.md に1行（daily-ops夜モード）
```

### 週末（どちらか1日、90〜120分）

```
1. [15分] 先週の数字をSkill⑥モードBに渡す → 翌週方針を1つ決める
2. [15分] 今週の台本5本を生成（Skill⑥モードA）
3. [60〜90分] 撮影バッチ: 5本まとめて画面録画・編集 → 投稿ストック化
※ 受注案件の納期が迫っている週は、撮影バッチを3本に減らして納品優先
```

### 金曜（＋15分）

週次レビュー: log.md集計 → **dashboard.md の週次KPIに1行追記、月次実績を更新**。
判断ルール:
- 提案10件で返信0 → 提案文か価格を見直す（Skill①のNG例と照合）
- 投稿15本でフォロワー100未満 → Skill⑥モードBでフック改善。4週連続未達なら Skill⑤で予備ジャンル（生活便利グッズ）への転換を検討
- フォロワー1,000到達 → その週のうちにTikTok Shopショーケース申請（research/2026-07-tiktok-shop-strategy.md のT2手順へ。商品分析はSkill⑤モードD）
- 受注が回り始めたら提案数を減らして制作時間を確保
